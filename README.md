# HEMS SmartPLC Updates

Official signed firmware updates for M5Stack StamPLC K141 running HEMS.

This repository distributes compiled firmware, signed update manifests and release notes only. Application source code is not stored here.

- Download official firmware from Releases.
- Enable automatic updates using StamPLC Companion.
- Firmware signatures and SHA-256 are verified on the device before activation.
- Initial OTA setup requires the HEMS Companion USB procedure; do not flash a partition table from another project.
- Wi-Fi passwords, device credentials and signing private keys are never published here.

Use only the firmware for your hardware and product. Binary availability does not grant a license to the private application source. Third-party notices accompany each release.
